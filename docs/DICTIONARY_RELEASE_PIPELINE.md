# Словарный выпуск LexiFlow

Эксперимент в `research/prototypes/sqlite_poc/` разделяет локальный импорт, редактуру, проверку прав и упаковку. Контракт выпуска и интеграция Android остаются предложениями. [Контракт пакета](DICTIONARY_PACKAGE_CONTRACT.md) · [Интеграция Android](ANDROID_DICTIONARY_INTEGRATION.md)

## Редакторский цикл

Из корня репозитория с Python 3.10+ и SQLite с поддержкой оконных функций:

```powershell
python -m unittest discover -s research/prototypes/sqlite_poc -v
python research/prototypes/sqlite_poc/review_queue.py export research/data/processed/milestone_exact.sqlite research/data/review/tasks.jsonl
python research/prototypes/sqlite_poc/review_queue.py suggest research/data/processed/milestone_exact.sqlite research/data/review/proposals.jsonl
python research/prototypes/sqlite_poc/review_queue.py validate research/data/processed/milestone_exact.sqlite research/data/review/decisions.jsonl
python research/prototypes/sqlite_poc/review_queue.py apply research/data/processed/milestone_exact.sqlite research/data/review/decisions.jsonl
python research/prototypes/sqlite_poc/review_queue.py progress research/data/processed/milestone_exact.sqlite
```

Сохраняйте в файле решений `entry_id`, `sense_id`, `snapshot_sha256`, `locator`, `classification`, `proposed_translation`, `decision`, `reviewer`, `method`, `reason`. Экспорт задачи добавляет заголовок, POS, позицию, исходную глоссу, до трёх строк контекста с доступными переводами и статус прав. `suggest` выдаёт эвристику, которую редактор может изменить. Для применения нужны явные `approved` и `human`, установленные редактором после проверки. Такая запись фиксирует заявление редактора. Подпись или проверка личности в PoC отсутствует. Одобрение кандидата может создать отдельный перевод со своим provenance и правами pending. Исходная глосса сохраняется.

`semantic_decision` хранит первое применение с хэшем решения. Повтор того же решения идемпотентен. Конфликт, устаревший locator или неправильное сочетание статьи, смысла и снимка отклоняются. Применение списка редакторских решений атомарно. Пересмотр ранее принятого решения требует будущего протокола отмены и замены. Обе служебные таблицы создаются при первой подтверждённой операции над staging.

В существующей очереди **153 глоссы и 458 свидетельств pending**. Локальный `research/data/review/milestone_release_priority.jsonl` содержит **24 AI-assisted предложения**, из которых 12 смешанных глосс, 11 кандидатов и один случай для уточнения. Отобраны частотная лексика, многозначность, фразовые глаголы, разговорные и неоднозначные записи. В этих 153 задачах явных `form-of` не найдено, сценарий закрыт искусственным набором. Файл приоритета предназначен для чтения и содержит поля задачи. Для подачи решений перенесите перечисленные выше поля в отдельный JSONL. На реальном снимке редакторских одобрений и разрешений на публикацию **0**.

## Права и состав выпуска

Операция `rights` принимает отдельный JSONL с `snapshot`, `locator`, `source_url`, `license_id`, `terms_url`, `attribution`, `modification`, `decision`, `reason` и `reviewer`. В прототипе каждое решение связано с точным элементом. Повтор идемпотентен, конфликт останавливает обработку. При сбое на следующей строке принятые ранее решения о правах сохраняются. Отсутствие ссылки на цитату не является основанием для разрешения. Права статьи, смысла, глоссы, её редакторского перевода, формы, примера и перевода примера проверяются раздельно. Медиа исключены из версии 1 и потребуют собственных решений о правах.

Wikimedia требует учитывать лицензию самого элемента, атрибуцию, изменения и условия ShareAlike, где они применимы. Для импортированного текста и медиа следует проверить страницу, историю и лицензию конкретного материала. Kaikki и Wiktextract описывают способ извлечения и структуру данных. Извлечение не заменяет происхождение конкретной строки. [Условия Wikimedia](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use) · [Kaikki English](https://kaikki.org/dictionary/English/) · [Wiktextract](https://github.com/tatuylonen/wiktextract)

Запуск экспортёра на реальной точной выборке завершился отказом из-за отсутствия одобрений и прав. Искусственные тесты подтверждают фильтрацию pending и excluded, контроль вложенности примера и его перевода, идемпотентность, стабильность повторного экспорта и отклонение испорченных пакетов.

## Поиск и дополнительный источник

Staging-поиск группирует по статье и смыслу до LIMIT, отдаёт приоритет точному совпадению и разрешает равенство ключей стабильной сортировкой. Формы привязаны к статье, в выпускном режиме требуется и допуск формы. На синтетических данных EXPLAIN подтвердил диапазонные индексы `entry_search`, `translation_search` и `form_search`. RANGE и LIMIT ограничивают диапазон и объём ответа. Широкий префикс всё ещё может потребовать ранжирования многих совпадений. У старых staging-файлов индекс форм появляется при повторном импорте в новую БД. Их редакторские очереди читаются в исходном виде.

Для трёх пропусков из диагностики вручную проверены страницы английского Wiktionary. На сайте есть идиома, фразовый глагол и разговорное написание. Это проверка страниц, покрытие конкретного снапшота Kaikki не измерено. Для выборочного адаптера закрепить ревизию, сохранить исходные секции языка, POS и порядок senses. Верхнеуровневые переводные блоки сохранять кандидатами с исходной меткой. Сопоставлять контекст и смысл с локальной редакцией вручную. Существующий `english_edition_shape` проверяет структуру на искусственных данных.
