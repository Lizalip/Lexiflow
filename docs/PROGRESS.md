## BUG-001 · Аварийное завершение при запуске

На корневом экране `MainActivity` передавала `0` в перегрузку `Toolbar.setNavigationIcon(int)`. AppCompat пытался загрузить ресурс с ID `0x0` и прерывал запуск. Теперь на корневых экранах используется `setNavigationIcon(null)`, а на вложенных остаётся стрелка возврата. Целевой аудит строк, drawable, стилей, меню и динамических действий не выявил других вызовов с недопустимым ресурсом `0`. Необязательная строка действия в `Screen` защищена проверкой перед `setText`.

Debug APK обновлён на Xiaomi 2502FRA65G с Android 16 (API 36) через `adb install -r`. До и после инструментального прогона `am start -W` вернул `Status: ok`, а `MainActivity` перешла в состояние resumed. В буфере аварий Logcat за это окно новых записей о падении LexiFlow нет. Пользовательские данные не очищались. Собраны debug APK и APK тестов, прошли 11/11 JVM-тестов и 10/10 инструментальных тестов на Xiaomi. Ручная приёмка и запуск на API 29 остаются открытыми. [Сценарий регрессии и результаты](TEST_PLAN.md#регрессия-bug-001)

Повторный `lintDebug` с локальным SDK, заданным через `ANDROID_HOME`, дал 0 ошибок и 3 прежних предупреждения о зависимостях. [Причина повторного прогона](TEST_PLAN.md#регрессия-bug-001)
