# LexiFlow Research · кандидат Stage 1

Кандидат рассчитан на локальный профиль `app.lexiflow.research`. Проверенный код Android опубликован в `c21a3ea5`. Пакет `bilingual-cefr-20000-marathon` собран на прежней базе. Манифест обновлён только для десяти дополнительных пар примеров. Содержимое кандидата и результаты ручной приёмки учитываются отдельно.

Поисковая SQLite совпадает с предыдущей по SHA-256. Поэтому покрытие прежних диагностических наборов относится и к новой паре: 48 из 55 точных, 50 из 55 с нормализацией, 201 из 264 точных, 208 из 264 с нормализацией и 79 из 128 точных прямых русских запросов. Это наличие ключей. Качество ранжирования и смыслов проверяется отдельно.

При добавлении примеров использованы только закреплённые ответы Tatoeba с прямой связью предложений. Кандидаты с другим POS, повтором оригинала в той же статье или неподтверждённым значением остались вне пакета. `research_upgrade.py --allow-enrichment` подтвердил отсутствие потерь и сохранение 318 587 прежних записей атрибуции. Пакет манифеста вырос на 8 042 байта, хеш SQLite совпадает с предыдущим.

Из корня репозитория выполните команды в PowerShell 7. Потребуются уже имеющиеся локальные словарные файлы, решения по примерам, Android SDK и JDK.

```powershell
python research/prototypes/sqlite_poc/research_example_package.py `
  research/data/processed/research-scaling/bilingual-cefr-20000-lexical-scale `
  research/data/interim/corpus-enrichment/tatoeba-api `
  research/data/processed/research-scaling/bilingual-cefr-20000-marathon `
  --decisions research/data/review/overnight-20000/usage-marathon-additions.json
./scripts/build-research-candidate.ps1 `
  -Dictionary research/data/processed/research-scaling/bilingual-cefr-20000-marathon `
  -Python (Get-Command python).Source
./scripts/verify-research-upgrade.ps1 -Python (Get-Command python).Source -Advanced morphology -MarathonUsage
```

Экспорт требует нового выходного каталога. Подписанный APK и отчёт сохранены локально в `.gradle/samsung-evidence/research-candidate-20261126-211027-860`. Код сборки проверяет подпись для API 29, профиль, отсутствие разрешения INTERNET, точное содержимое пары и размер APK до 100 000 000 байт. SHA APK относится к указанному экземпляру, поскольку подпись зависит от локального ключа.

Проверка сравнивает тестовый личный перевод, заметку, подборку, карточки и историю. Новых аварий тестового профиля в журнале нет.

## Установка в рабочий Research

После изолированных проверок Android принял APK поверх рабочей установки. Подпись совпала с предыдущей. Установка заняла 3,76 с, активный указатель на новую пару появился через 60,84 с после команды запуска. Установка поверх старой квитанции может включать повторную проверку прежней пары. Этот замер указателя охватывает другой сценарий, чем холодный замер одного пакета в изолированном профиле.

Хеши установленного APK, обеих SQLite и активного манифеста совпали с таблицей. Резервный манифест имеет SHA-256 `ece256e6df8c53305fb9f2ae6887cfbf1bf4575fe1e2ba373a2ce90b93eb4489`. Активная и резервная пары занимают 275 548 582 байта. Новых аварий LexiFlow Research не зарегистрировано. Личные данные проверялись на тестовых данных в отдельном профиле. Рабочий профиль обновлён без очистки. Протокол находится в `.gradle/samsung-evidence/marathon-installed-20261126-212429-325`.

## Приёмка

- В исследовательском режиме требуется вручную проверить поиск в обоих направлениях, длинные статьи, исходную атрибуцию и личный словарь после обновления.
- На Android 10 и устройстве с 3 ГБ ОЗУ нужны замеры первого запуска, навигации и поиска. На Samsung остаются проверка физического авиарежима, TalkBack и установленного офлайн-голоса.
- Допуск production требует человеческой проверки смысла, решения о лицензиях и явного разрешения поставки. Обычная release-сборка исключает словарь Research. Визуальная приёмка Stage 2 ведётся отдельно.

Разрешение на дополнительные данные требуется для английского train UD EWT r2.16 объёмом 13,5 МБ и для крупных экспортов Tatoeba. Страницы OpenCorpora в прямом доступе вернули служебную страницу nginx. Для форм Kaikki остаются открыты точная ревизия исходной публикации и подтверждение атрибуции.
