# LexiFlow · итоговая приёмка Stage 1

С 27 ноября 2026 года приёмка Stage 1 оценивает учебную демонстрацию. Основной сценарий включает поиск, статью, сохранение значения, карточку, повторение и прогресс. Производственные показатели и публикация коммерческой сборки относятся к Stage 3. Зафиксированные ниже замеры и проверки описывают исследовательские сборки на соответствующих ревизиях.

## Стабильная установка и отдельный кандидат

Для ручной приёмки используется установленный на Samsung `bilingual-cefr-20000-marathon` с 40 парами примеров в 25 статьях. В этот проход его APK воспроизведён побайтово. Снимок с 48 парами подготовлен отдельно и ожидает проверки на физическом устройстве. [Стабильный Research RC](STAGE1_RESEARCH_RC.md)

Новый `bilingual-cefr-20000-final-usage` сохраняет оба словника по 20 000 написаний, 43 694 статьи, 60 781 значение, 116 665 переводов, 1 696 грамматических анализов, 6 914 статей и 6 105 написаний с CEFR-J. В нём **48 примеров в 30 статьях**. SQLite прежняя: 93 130 752 байта, SHA-256 `5734d9d946f36f16f028de301034ba38830b9f27eef768108eac2a17db00a130`. Манифест занимает 44 657 219 байт, SHA-256 `72d5c24cee96d23303ca613f0e8e33ed5a7082c46268252b467401497621e51a`. Суммарный размер двух файлов 137 787 971 байт.

APK занимает 77 195 846 байт. SHA-256 `24f08e94ac89c8a0c24cecb49c3b8a65f62e19769a54ed5e43752b4badc22b25`. Файл сохранён в `.gradle/samsung-evidence/research-candidate-20261126-221927-790/research.apk`. Реализация читателя зафиксирована в `6a92a4ae`. Проверены подпись с нижней границей API 29, application ID, отсутствие INTERNET, точный состав ZIP и дайджесты ассетов. Эти проверки статические.

Шесть ограниченных запросов к официальному хосту API Tatoeba вернули 60 строк и 39 уникальных пар с прямой связью, текстом, автором и лицензией. Ответы заняли 23 010 байт. Список импорта включает восемь пар с однозначно выбранными английскими статьями и POS. Один запрошенный ключ отсутствует как заголовок установленного корпуса. Desktop-валидация и сверка обновления подтвердили сохранение всех прежних записей, примеров, форм и 318 607 атрибуций. В новом пакете есть отдельная атрибуция обеих сторон каждой добавленной пары. [API Tatoeba](https://api.tatoeba.org/openapi.json) · [Условия использования](https://en.wiki.tatoeba.org/articles/show/using-the-tatoeba-corpus)

Решения находятся локально в `research/data/review/editorial-qa-v1/final-usage-decisions.json`, закреплённые ответы — в `research/data/interim/corpus-enrichment/tatoeba-final-dev-relevance`. Для воспроизведения используйте `research_example_package.py` с базой `bilingual-cefr-20000-marathon`, этим каталогом ответов, новым каталогом назначения и параметром `--decisions`. APK собирается `scripts/build-research-candidate.ps1` с получившейся парой.

## Отдельный вариант с дополнением RU–EN

`bilingual-cefr-final-ru-supplement` добавляет 243 отсутствующие пары «лемма + POS» из того же проверенного FreeDict RU–EN. Выпуск сохраняет первые 20 000 русских написаний, исходные значения, UUID, формы, CEFR и 48 примеров. Локальная сверка с установленным пакетом дала нулевые расхождения среди прежних записей и атрибуций. Итоговая пара содержит 20 000 EN и **20 243 RU написания**, 43 937 статей, 61 203 значения и 117 607 переводов.

В фактически собранной SQLite на отложенном test UD Russian GSD теперь есть 990 из 3 163 типов и 4 326 из 7 508 токенов. Сначала проверяется отдельная Researchcheck-сборка. Инструментальный сценарий `finalCandidateShowsNewAttributedUsageAndDirectRussianArticles` получает точную версию из манифеста через `lexiflowFinalCorpus`, проверяет два новых примера и, для варианта дополнения, новый прямой русский результат.

## Проверки приёмки

| Область | Установленный RC | Следующая проверка |
| --- | --- | --- |
| EN ↔ RU, статья, формы, CEFR и примеры | Проверено на Samsung в предыдущем прогоне | Открыть восемь добавленных примеров в изолированном APK и сверить подписи авторов |
| Заметки, карточки, подборки и история | Обновление, перезапуск и откат проверены с тестовыми данными | Гибель процесса внутри валидации и откат при отказе записи события |
| Автономность | Манифест APK без INTERNET, словарь и Room локальные | Физический авиарежим и установленный английский офлайн-голос |
| Android 10 / API 29 | Минимальная версия задана | Рантайм на API 29. Список AVD пуст. Каталоги 30 и 37.1 не содержат установленного `system.img` |
| Доступность и скорость | Исторические замеры готовы для опорного RC | TalkBack, масштаб текста, альбомная ориентация и модель с 3 ГБ ОЗУ |
| Корпус и распространение | Research-профиль и 0 человеческих допусков | Выбрать вариант выпуска, подтвердить права, затем согласовать артефакт |

Для проверки Android 10 создайте AVD с согласованным образом API 29 в Android Studio Device Manager, подтвердите `adb shell getprop ro.build.version.sdk` и запустите `:app:connectedDebugAndroidTest` с `-Plexiflow.isolatedRuntimeCheck=true`. Ручной перечень для владельца и варианты выпуска описаны отдельно. [Решение о выпуске](STAGE1_RELEASE_DECISION.md)

Проверки текущей ревизии дали 89 успешных Python-тестов конвейера, три успешных теста APK-инспектора, один тест локального браузерного экспорта и 21 JVM-тест. Собрались debug, release, тестовый и Research APK. Lint на изолированной копии прошёл, в исходной папке воспроизводится ошибка `PropertyEscape` в локальной конфигурации SDK. Производственный шлюз отверг новый валидный Research-пакет даже с правильным SHA. Android-инструментарий собран. При отсутствии подключённого устройства проверки нового корпуса, реальной гибели процесса и отката записи Room остались открыты.

## Источники, требующие решения

- Закреплённый английский train UD EWT r2.16 занимает около 13,5 МБ. Он нужен для измерения дополнительного покрытия. Локально подтверждены dev и test. Для полного train требуется разрешение. [Файл train](https://github.com/UniversalDependencies/UD_English-EWT/blob/r2.16/en_ewt-ud-train.conllu)
- Официальные HEAD-запросы подтвердили отдельный архив прямых связей EN–RU (5 041 095 байт), подробные таблицы EN (35 004 488) и RU (23 741 971), а также таблицы CC0 EN (1 288 689) и RU (516 641). Для воспроизводимого соединения по ID с владельцами и индивидуальной лицензией потребуется разрешение на 65 592 884 байта. Общий архив связей занимает 150 798 085 байт. Файлы этих размеров остаются на стороне источника. [Экспорты Tatoeba](https://tatoeba.org/en/downloads) · [EN–RU связи](https://downloads.tatoeba.org/exports/per_language/eng/eng-rus_links.tsv.bz2) · [EN тексты](https://downloads.tatoeba.org/exports/per_language/eng/eng_sentences_detailed.tsv.bz2) · [RU тексты](https://downloads.tatoeba.org/exports/per_language/rus/rus_sentences_detailed.tsv.bz2) · [EN CC0](https://downloads.tatoeba.org/exports/per_language/eng/eng_sentences_CC0.tsv.bz2) · [RU CC0](https://downloads.tatoeba.org/exports/per_language/rus/rus_sentences_CC0.tsv.bz2)
- OPUS предлагает параллельные корпуса и выравнивания с ID. Для отбора учебных примеров из другого корпуса сначала нужны предметная выборка, проверка прямого соответствия и происхождение с условиями каждой стороны. В текущем кандидате источником предложений служит Tatoeba. [Форматы OPUS](https://opus.nlpl.eu/download-formats)
- Файл английских парадигм UniMorph `eng` по метаданным репозитория занимает 18 022 905 байт. Для импорта потребуются закреплённый снимок, проверка маппинга тегов и отдельное решение по источнику. [UniMorph English](https://github.com/unimorph/eng)
- Для включения русских морфологических кандидатов из UD GSD потребуется согласовать отдельные теги и ограничения владельца статьи. Кандидаты Kaikki требуют подтверждения происхождения выгрузки. [Диагностика и редактура](STAGE1_LEXICAL_QA.md)
