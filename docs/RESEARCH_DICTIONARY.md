# Локальный исследовательский словарь Stage 1

LexiFlow Research на Samsung SM-X516B (Android 14, API 34) загружает FreeDict EN–RU 2025.11.23 и поддерживает поиск в обе стороны и обучение на найденных значениях. Установленная версия обновлена до 20 000 написаний. Пакет 5 000 остаётся вариантом сборки по умолчанию и базой приведённого ниже исторического замера. Обновление, дополнительные размеры и их проверки описаны в ночной контрольной точке. Статусы человеческой редакторской проверки и допуска к распространению открыты. [Ночная контрольная точка](OVERNIGHT_CHECKPOINT.md)

## Источник и отбор

Архив `freedict-eng-rus-2025.11.23.src.tar.xz` имеет SHA-256 `f3dadcc29d7df6e77edb13b98a2ba2c3fac002852eddd8b557637f0b13d39c39`. В заголовке TEI указана CC BY-SA 3.0. Атрибуция сохраняет цепочку FreeDict / WikDict / DBnary / Wiktionary, снимок, исходный локатор и изменения LexiFlow. Лицензия сопровождает словарные материалы отдельно от кода клиента. При распространении адаптированных данных потребуется сохранить условия ShareAlike, атрибуцию и сведения об изменениях. Допуск и способ распространения требуют отдельного решения владельца. [FreeDict Downloads](https://freedict.org/downloads/) · [FreeDict Documentation](https://freedict.org/documentation/) · [WikDict](https://www.wikdict.com/page/download) · [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/legalcode)

Порядок отбора задаёт локальный SUBTLEX-US ZIP с SHA-256 `67e595da1b399d2a21e25a1466a8d9f242f21a219c6bbbd3e089c4779ad83856`. Для отдельной квоты выражений используется минимальная частота компонентов. Это эвристика, частоту выражения целиком она не измеряет. Из 48 806 допустимых написаний в первых 5 000 зарезервировано 250 выражений. Скрининг исключил 12 978 кандидатных строк по форме написания или части речи и 33 по виду перевода. Исходные русские тексты сохранены, части речи и значения хранятся раздельно. UUID привязаны к снимку и локатору, поэтому совпадают у одной и той же записи в вариантах разного размера. Соответствие UUID между выпусками источника требует отдельного исследования.

## Воспроизведение

Откройте корень проекта в Android Studio. Для исследовательского APK используйте задачу `:app:assembleDebug` с `-Plexiflow.research=true` в Gradle Run Configuration либо в терминале Studio. В списке вариантов используется `debug`, отдельного варианта `researchDebug` нет. Передайте существующий Python через `-Plexiflow.python`. Из корня проекта на Windows выполните команды со своим путём к Python.

```powershell
$py = 'C:/path/to/python.exe'
$base = 'research/data'
$pair = "$base/processed/research-app/dictionary-research"
& $py research/prototypes/sqlite_poc/research_package.py export "$base/processed/enrichment_freedict.sqlite" "$base/interim/corpus-enrichment/freedict-eng-rus-2025.11.23.src.tar.xz" "$base/interim/corpus-enrichment/subtlexus2.zip" $pair --size 5000
& $py research/prototypes/sqlite_poc/research_package.py validate $pair
& $py research/prototypes/sqlite_poc/research_diagnostics.py "$base/processed/enrichment_freedict.sqlite" $pair --kaikki "$base/processed/enrichment_kaikki_metadata.sqlite"
.\gradlew.bat :app:assembleDebug "-Plexiflow.research=true" "-Plexiflow.python=$py"
```

Для сборки установленного на Samsung варианта добавьте `-Plexiflow.researchDictionary=research/data/processed/research-scaling/20000`. Для локального расширенного варианта укажите `research-scaling/30000` с тем же базовым путём. Инструментальный прогон `scripts/verify-research-upgrade.ps1 -Python $py -Measure30000` использует отдельный ID `app.lexiflow.researchcheck`. Ключ `-UpdateResearch` после проверок разрешает обновление пользовательского Research поверх текущей установки.

Если пара уже сформирована, начните с её проверки. Экспорт требует нового каталога и сохраняет существующую пару. Для установки выберите нужное устройство в Studio, затем установите локальный APK из `.gradle/research-build/app/outputs/apk/debug/app-debug.apk`. В списке приложений откройте **LexiFlow Research**. На Samsung проверьте видимость пометки источника, `book`, обратный поиск `книга` и сохранённую карточку после перезапуска. Обычный профиль и личная Room-база изолированы по application ID.

Локальные результаты находятся в `research/data/processed/research-app/dictionary-research`, `research/data/processed/research-diagnostics-5000.json`, `research/data/processed/research-scaling` и `.gradle/samsung-evidence/frames-20261125-225514-457`. APK, кадры и данные остаются на рабочем компьютере.

## Предложение для production policy

Сохранить структурные проверки, SHA-256, индексы, внешние ключи и прослеживаемость для каждой записи. Предложение к согласованию предусматривает отдельные страты частотной лексики, многозначных слов, выражений и терминов. На каждой страте измерять долю ошибок на зафиксированной случайной выборке. Общую пригодность источника подтверждать на точном снимке, а неоднозначные значения и лицензионные исключения разбирать отдельно. Предварительная автоматическая или AI-assisted классификация может задавать приоритет очереди. Решения редактора, изменения и повторные проверки хранить по версиям. Порог качества, схему редакторской выборки и разрешение распространения утверждает владелец. До такого решения действуют индивидуальные требования действующего release-конвейера.
