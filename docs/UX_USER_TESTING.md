# LexiFlow Research · правки после пользовательского тестирования

| Требование | Изменение |
| --- | --- |
| UX-001 | Слово, основной перевод, варианты выбранного значения и динамик собраны в одной карточке. Другие значения выбираются по тексту перевода. Далее идут Definition, две строки транскрипций, часть речи и CEFR. Формы и примеры доступны в «Подробнее». Источники и лицензии открываются текстовой кнопкой внизу. |
| UX-002 | Пустое состояние, поле личного поиска и навигация сохранены. «Открыть подборки» и «Найти слово в словаре» занимают ширину контента. |
| UX-003 | Результат показывает слово и до трёх переводов одного значения. Поиск сохраняет существующее ранжирование, поиск по формам и обратное направление. Динамик использует установленный английский офлайн-голос и обрабатывает нажатие отдельно от строки. |

Единая кнопка сохраняет выбранное значение по существующим идентификаторам статьи и значения. Запись и карточка для перевода создаются в одной транзакции. Уже имеющиеся карточки, личные переводы, история и расписание переиспользуются. После добавления видна надпись «В моём словаре». Для значения без перевода можно сохранить запись и позже добавить свой перевод через личный словарь. Схема базы и алгоритм расписания прежние.

В используемом Research-пакете нет MP3-ассетов и Android-проигрывателя MP3. Аудиоссылки в исследовательских материалах сохранены. Для текущей сборки доступность динамика зависит от наличия установленного локального английского голоса.

## Качество перевода `one`

Для числительного у источника в одном значении пять цитат, начиная с «раз», затем «оди́н», «едини́ца», «одна́», «одно́». Порядок подтверждают идентификаторы переводов 51026–51030 и локаторы `entry/43119/sense/0/cit/0/quote/0…4`. Отдельного поля приоритета нет. В UI видны все варианты. Выбор общеупотребительного перевода остаётся задачей редакторской разметки значений и приоритетов.

## Проверки и сборка

Собраны debug, тестовый APK и Research APK. Прошли 24 JVM-теста. Android Lint прошёл на копии исходников с локальным SDK через `ANDROID_HOME`. Проверка `git diff --check` прошла.

Сквозной Espresso-сценарий прошёл на Xiaomi 2502FRA65G с Android 16 в отдельном Research-профиле. Он проверил размеры кнопок пустого личного словаря и обе ветви навигации, компактную выдачу, статью, добавление и оценку карточки, состояние после повторного открытия, личный поиск и подборку. На `one` проверены Definition и несколько вариантов транскрипции, на `blackboard` отсутствие Definition, на прямой статье `дом` отсутствие IPA, CEFR и динамика. Новых аварий приложения в Logcat не было.
