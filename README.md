# LexiFlow для Android

LexiFlow — автономный прототип словаря EN ↔ RU для учебной и проектной демонстрации. С подключённым Research-словарём можно найти слово, сохранить конкретное значение, начать учить его по карточке и увидеть результат на вкладке «Прогресс». В «Моём словаре» доступны личные переводы, заметки и подборки. Значок в верхней панели открывает настройки.

Для показа важны понятные завершённые сценарии, визуальная подача и стабильность на демонстрационном устройстве. Подготовка коммерческого выпуска относится к Stage 3.

## Запуск в Android Studio

Клиент написан на Java и использует XML, Material Components, AndroidX ViewModel и Gradle Wrapper. В текущей рабочей копии запускайте модуль `app`. Локальная ссылка `origin/main` указывает на исследовательскую версию проекта.

| Путь | Содержимое |
| --- | --- |
| `app/src/main/` | Манифест, Java-код и XML-ресурсы приложения |
| `app/src/test/`, `app/src/androidTest/` | Тесты модели состояния на JVM и инструментальный тест навигации |
| `gradle/wrapper/`, `*.gradle.kts` | Версия Gradle и конфигурация сборки |
| `docs/` | Техническая документация фундамента |
| `research/notebooks/`, `research/docs/` | Исследовательские материалы в дереве `origin/main`. Их доступность в рабочей копии описана в статусе проекта. |

[Статус и план очистки Git](docs/PROGRESS.md) · [Архитектура](docs/ARCHITECTURE.md) · [План тестирования](docs/TEST_PLAN.md)

### Порядок запуска

1. Откройте через **File → Open** каталог проекта, содержащий `settings.gradle.kts`.
2. В **SDK Manager** установите Android SDK Platform 37 (37.0) и предложенные Gradle инструменты сборки. В настройках Gradle выберите встроенный JBR Android Studio. Локальная сборка использует JBR 25.0.3, Java-код компилируется с уровнем языка 17.
3. Выполните **Sync Project with Gradle Files**. Первый запуск на чистой машине требует доступа к Google Maven, Maven Central и дистрибутиву Gradle. Версии закреплены в файлах сборки и Wrapper.
4. Выберите конфигурацию **app** и устройство Android 10 (API 29) или новее. Для эмулятора создайте устройство через **Device Manager**, установите образ и дождитесь его загрузки.
5. Нажмите **Run ▶**. Первым откроется «Словарь» с полем «Слово или выражение».

## Проверки в PowerShell

Команды выполняются в корне проекта. Для терминала задайте `JAVA_HOME` на JBR Android Studio и `ANDROID_HOME` на Android SDK либо укажите путь к SDK через локальный `local.properties`.

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug
.\gradlew.bat :app:assembleDebugAndroidTest
.\gradlew.bat :app:connectedDebugAndroidTest
```

Последняя команда запускает Espresso на подключённом устройстве. Debug APK находится в `app/build/outputs/apk/debug/app-debug.apk`, отчёты проверок — в `app/build/reports/`.

## Архитектура

| Компонент | Ответственность |
| --- | --- |
| `ui/MainActivity` | Подключает Material-компоненты из XML, обрабатывает ввод, системные отступы, выбор вкладок и возврат. |
| `ui/Screen` | Определяет семь экранов, их тексты, основные действия и родительские разделы. Три вкладки используют единый редактируемый XML-макет пустого состояния. |
| `ui/FoundationViewModel` | Хранит маршрут, экран возврата из настроек и черновик запроса в `SavedStateHandle`. Черновик живёт в рамках задачи Android. |
| `data/DictionaryRepository` | Сообщает, для каких языков на устройстве установлен словарь. |
| `data/LocalDictionaryRepository` | Возвращает пустой набор для сборки без корпуса. Будущее локальное хранилище можно подключить за этим интерфейсом после утверждения модели. |

Тексты, палитра и стили находятся в `app/src/main/res/values/`. Тема использует фон, чернильный, мятный и синий цвета из HANDOFF и коралловый акцент. Для кириллицы и системного масштабирования выбран системный sans-serif. Arsenal остаётся вариантом для брендовой типографики.

## Граница текущей реализации

Текущий результат предназначен для ревью навигации и оформления. База статей, ETL, поиск по корпусу, сохранение слов и расписание повторений требуют отдельного этапа. Полная первая стадия продукта шире этого каркаса.

## Локальное окружение Windows

На проверенной машине тестовый JVM-процесс завершался с `ClassNotFoundException: GradleWorkerMain` при использовании стандартного кэша в профиле с кириллицей. Для повторения успешного прогона из корня этого проекта используйте:

```powershell
.\gradlew.bat --gradle-user-home .gradle/verification :app:testDebugUnitTest
```

Первый запуск с новым каталогом кэша может потребовать загрузки зависимостей. Каталог исключён из Git.
