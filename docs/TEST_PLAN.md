# План проверки Android-фундамента

## Автоматические проверки

Выполнять из корня проекта с JBR и Android SDK, описанными в [README](../README.md).

| Команда PowerShell | Проверяемое свойство | Свидетельство |
| --- | --- | --- |
| `.\gradlew.bat assembleDebug` | Компиляция, объединение ресурсов, упаковка | `app/build/outputs/apk/debug/app-debug.apk` |
| `.\gradlew.bat --gradle-user-home .gradle/verification testDebugUnitTest` | Начальное состояние, возвраты из всех трёх вложенных экранов через настройки, чтение черновика и маршрута второй моделью из того же SavedStateHandle | `app/build/test-results/testDebugUnitTest/TEST-app.lexiflow.ui.FoundationViewModelTest.xml` |
| `.\gradlew.bat lintDebug` | Статический анализ конфигурации, Java и ресурсов | `app/build/reports/lint-results-debug.html` |
| `.\gradlew.bat connectedDebugAndroidTest` | Espresso открывает подборки, пересоздаёт Activity и проверяет возврат в личный словарь | Требуется запущенный эмулятор или устройство с USB-отладкой |

При стабилизации выполнены первые три проверки. Результаты зафиксированы в [PROGRESS](PROGRESS.md). Инструментальный тест подготовлен; результат выполнения на устройстве отсутствует.

## Короткий ручной прогон в Android Studio

| Шаг | Ожидаемый результат |
| --- | --- |
| Запустить `app` в авиарежиме на Android 10+. | Открывается «Словарь», видны языковая пара, поле и сообщение о пустой базе. |
| Ввести смешанный текст с «ё», дефисом и апострофом. Открыть статью и вернуться стрелкой. Затем очистить поле. | Открывается пустая статья. После возврата текст сохраняется, кнопка очистки удаляет его. |
| Открыть «Мой словарь» → «Подборки», повернуть устройство и нажать системную кнопку «Назад». | Поворот сохраняет подборки, возврат открывает «Мой словарь». |
| Открыть «Повторение» → «Прогресс» → «Настройки», вернуться дважды. | Показаны пустые состояния и статус базы. Возврат проходит через прогресс к повторению. |
| Повернуть устройство при вводе, увеличить системный шрифт, открыть клавиатуру. | Запрос сохраняется, содержимое прокручивается, клавиатура и системные панели не перекрывают доступ к действиям. |

Для каждого прогона записать модель устройства или AVD, API, дату, результат шага и способ воспроизведения отклонения. Расширенная проверка включает TalkBack, жестовую навигацию и восстановление задачи после уничтожения фонового процесса. Эти сценарии остаются непроверенными.
