# Проверка лексики · Stage 1

## Исходная редакторская выборка

Проверены 280 уникальных значений из семи исходных страт, по 40 на страту. 619 строк перевода совпали с SQLite кандидата и с исходным staging FreeDict по точному локатору, снимку, статье, значению и тексту. Все записи имеют обоснование. В 14 ранних оценках отдельные поля неопределённости и действия отсутствуют, поэтому интерфейс оставляет их пустыми. Одобрений человеком 0.

| Наблюдение | Количество значений |
| --- | ---: |
| Предварительно правдоподобные | 139 |
| Проблемы или неопределённость высокой тяжести | 33 |
| Средней тяжести | 93 |
| Низкой тяжести | 15 |
| Контекст статьи содержит исходное определение | 275 |
| Статья содержит более одного значения | 184 |
| Значение содержит несколько переводов | 172 |
| Написание имеет не менее 10 000 вхождений в SUBTLEX-US | 73 |

Высокая тяжесть включает 17 сигналов смешения значений, 11 возможных расхождений POS, 4 возможных расхождения смысла и 1 нерешённое соответствие. Собственные определения источника показываются как контекст статьи. Сводка содержит группы по POS, страте, числу значений в статье, числу переводов, наличию определения и частоте. SUBTLEX-US указывает частоту написания, например для слова с несколькими значениями это общая частота. Страты намеренно смещены к задачам редактуры. Долю оценок нельзя переносить на весь корпус.

## Локальная редактура

В PowerShell из корня репозитория можно создать рабочую страницу так:

```powershell
python research/prototypes/sqlite_poc/research_editorial_audit.py `
  research/data/review/overnight-20000 `
  research/data/processed/research-scaling/bilingual-cefr-20000-marathon `
  research/data/processed/enrichment_freedict.sqlite `
  research/data/interim/corpus-enrichment/subtlexus2.zip `
  research/data/review/editorial-qa-rerun
```

Укажите новый выходной каталог. В нём будут `summary.json`, `queue.json` и `index.html`. В интерфейсе есть фильтры части речи, категории и тяжести. Строки упорядочены по тяжести и частоте, показывают текст, локаторы, контекст и предварительную оценку. Отложенные задачи сохраняются в файле сессии. При принятии формулировки или предложении отклонения с комментарием выгружается существующий формат JSONL со статусом `proposed`. UUID Research используются для чтения и проверки владельца. Ключи выгрузки берутся из точной строки staging FreeDict. Отдельное человеческое утверждение и лицензионный допуск по-прежнему необходимы.
