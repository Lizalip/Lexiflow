# Статус LexiFlow на 25 ноября 2026 года

Срез относится к локальной рабочей копии Android-фундамента. Паспорт задаёт требования продукта, а HANDOFF от 24 ноября определяет границы стадий. Приёмка первой стадии ещё предстоит.

| Статус | Что установлено |
| --- | --- |
| Implemented — реализовано | Модуль Android, сборка debug APK, семь маршрутов с пустыми состояниями, ввод и очистка запроса, возврат между экранами, сохранение состояния задачи через ViewModel. |
| Partially implemented — частично | У словаря, статьи, личного словаря, подборок, повторения, прогресса и настроек есть представления. Доступность словаря определяется репозиторием, который сейчас возвращает пустой набор языков. |
| Planned — запланировано | Для полной первой стадии потребуются согласованные данные, локальное хранилище, поиск EN ↔ RU, сохранение слов и повторение. |
| Not tested — не проверено | Запуск на устройстве, Espresso, восстановление задачи после уничтожения процесса системой, доступность, автономная работа на контрольном устройстве. |
| Blocked — заблокировано | Приёмка интерфейса ожидает прогона на устройстве. Включение корпуса ожидает согласования источников, прав, модели и способа поставки. |

## Основания для работы с данными

**Database Design Draft, 25 ноября 2026 года.** На основании сохранённых результатов аудита предложены логическая и физическая модели словарного и личного хранилищ. Статус — **черновик, не утверждён**. Есть описание идентичности значений, прав на элементы, двустороннего поиска, связей и индексов. Существующий Android-репозиторий данных возвращает пустой набор языков. Реализация, измерения на устройстве и проверка миграций остаются запланированными. [Проект модели](DATABASE_DESIGN_DRAFT.md) · [ER-диаграммы](DATABASE_ERD.md)

Предварительный отчёт перечисляет источники-кандидаты и условия оценки. Итоговый Data Source Audit Report анализирует сохранённые результаты ноутбука по выгрузке Kaikki из русского Викисловаря. В отчёте указаны 72 487 записей и 104 902 объекта значений. У 21,34 % значений есть непустой пример. Подсчёты описывают исследованную выгрузку. Повторная загрузка исходных данных, подтверждение прав и проверка качества готовых карточек в стабилизацию не входили.
