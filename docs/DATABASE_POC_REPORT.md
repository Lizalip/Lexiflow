# Локальная проверка словарного прототипа

25 ноября 2026 года. Эксперимент продолжает [перенесённый отчёт](DATABASE_POC_CHAT_REPORT.md). Исходные результаты — 23 теста в Linux на искусственных данных. Локально первый прогон на Windows дал 22 успешных теста и ошибку очистки временной базы из-за открытого SQLite-соединения. После закрытия соединения прошли 23 исходных теста, после расширения — **31 из 31**. Среда Windows, Python 3.12.14, SQLite 3.53.1.

## Локальные выборки Kaikki

Известный JSONL был доступен через файловый путь уже запущенной WSL. Импорт выполнялся Python из Windows с чтением исходника и записью небольших SQLite-выборок в игнорируемый каталог репозитория. Версия выгрузки независимо не подтверждена. Размер **87 009 307 байт**, SHA-256 `8cff3c5121393abf82909c5946217cc44fa9b06c640876705edb38d65dfe6894`.

Первые 100 входят в первые 1 000. Exact и reservoir просмотрели 72 487 физических строк. Exact воспроизвёл 17 совпавших написаний из 24, из них у семи есть глосса и переведённый пример. Первые 1 000 также воспроизвели 642 написания из аудита. В выборках не обнаружены пропущенные или повторяющиеся внешние ID значений. Сохранённый аудит всего корпуса фиксирует повторы, а их сохранение в импорте подтверждает искусственный регрессионный тест.

Для первых 1 000 строк глосса отсутствует у 14 из 3 187 значений, пример — у 2 418 из 3 187, переведённый пример — у 2 527 из 3 187. Метрики присутствия используют знаменатель соответствующего уровня и не оценивают качество. Последовательная и целевая выборки нерепрезентативны. Reservoir равномерно выбирает строки, поэтому вероятность отбора написания или значения зависит от структуры записей. Малые выборки не дают оценки всего корпуса.

У всех четырёх баз `integrity_check` вернул `ok`, `foreign_key_check` — ноль нарушений. Проверено соответствие снимков и исходных локаторов у значений и их статей. Из exact-базы экспортировано 153 локальные задачи на классификацию глосс. Проверенных лексических переводов в четырёх базах **0**. Импорт хранит глоссу и перевод примера раздельно, все свидетельства остаются pending. Измерения release lookup на реальном импорте ожидаемо не дали карточек.

## Воспроизведение

В PowerShell из корня репозитория задайте `$source` на проверенный доступный JSONL. Выходные пути должны быть новыми. Команда экспорта создаёт файл с исходными глоссами в игнорируемом каталоге.

```powershell
python -m unittest discover -s research/prototypes/sqlite_poc -v
New-Item -ItemType Directory -Force research/data/processed,research/data/review
python research/prototypes/sqlite_poc/run_import.py $source research/data/processed/first100.sqlite --limit 100
python research/prototypes/sqlite_poc/run_import.py $source research/data/processed/first1000.sqlite --limit 1000
python research/prototypes/sqlite_poc/run_import.py $source research/data/processed/exact.sqlite --method exact --limit 1000
python research/prototypes/sqlite_poc/run_import.py $source research/data/processed/random.sqlite --method random --seed 42 --limit 100
python research/prototypes/sqlite_poc/review_queue.py export research/data/processed/exact.sqlite research/data/review/tasks.jsonl
python research/prototypes/sqlite_poc/benchmark.py
```

## Производительность

Искусственные базы, одна статья, одно значение и один перевод на запись. Размер включает индексы. У каждого префикса два замера: первый запрос с новым SQLite-соединением и 100 повторов в том же соединении. Кэш ОС сохранялся. Лимит выдачи 20. Значения в миллисекундах.

| Статей | Размер в байтах | Путь | Первый | Медиана повторов | p95 повторов |
| ---: | ---: | --- | ---: | ---: | ---: |
| 5 000 | 3 907 584 | EN → RU | 1,55 | 0,52 | 0,61 |
| 5 000 | 3 907 584 | RU → EN | 1,48 | 0,61 | 0,76 |
| 20 000 | 15 347 712 | EN → RU | 1,50 | 0,64 | 0,94 |
| 20 000 | 15 347 712 | RU → EN | 1,95 | 0,64 | 1,02 |

На реальных выборках и искусственных базах `EXPLAIN QUERY PLAN` показал диапазонный `SEARCH` по `entry_search` и `translation_search`, с временными B-tree для DISTINCT и ORDER BY. Обратный план на реальной базе проверен при пустой таблице переводов, замеры с результатами сделаны на искусственной. Поиск по `form.search_key` в базе первых 1 000 строк даёт `SCAN form`. Перед включением форм нужен индекс по ключу и фильтр языка и прав статьи, значения и формы. Разные подходящие переводы одного sense могут занимать несколько строк. Перед релизом следует решить, группировать ли выдачу по sense до LIMIT, и измерить её на широких префиксах. Это измерения Windows, а устройства Android и полный корпус требуют отдельных прогонов.

Полного реестра лицензий, структурированной атрибуции, media, pron_audio, illustration, form_feature, tag, sense_tag и level нет. Локальная схема не содержит сохранений, своих переводов, подборок, карточек и событий. Метаданные и issue появились для диагностики PoC. Source/release и языковые поля сведены к необходимому минимуму, в том числе язык вложенных текстов выведен из контекста выгрузки. Индексы охватывают два поисковых пути и основные связи. Предложение не утверждает физическую схему.

## Дополнительные источники

- **English Wiktionary / Kaikki.** На странице English указаны выгрузка enwiktionary от 1 октября 2026 года и извлечение от 30 октября. Полный postprocessed JSONL отмечен устаревающим. Для небольшой проверки использовать страницы выбранных словоформ, зафиксировать ревизию, затем сравнить форму записи с документацией Wiktextract. Добавлена изолированная проверка формы синтетической записи. Она учитывает, что верхнеуровневые кандидаты переводов нельзя автоматически привязать к senses по написанию. Полная выгрузка и внешний образец не загружались. [Kaikki English](https://kaikki.org/dictionary/English/) · [Сырые выгрузки](https://kaikki.org/dictionary/rawdata.html) · [Wiktextract](https://github.com/tatuylonen/wiktextract)
- **Права English Wiktionary.** Страница описывает CC BY-SA 4.0 и GFDL для оригинальных текстов. Цитаты, встроенные материалы и медиа требуют отдельной проверки происхождения и применимых условий. Этот обзор не меняет статус реальных Evidence. [Wiktionary Copyrights](https://en.wiktionary.org/wiki/Wiktionary:Copyrights)
- **Tatoeba.** Следующая проверка должна зафиксировать версию выгрузки предложений, идентификаторы обоих предложений, ребро перевода, авторство и лицензию каждого текста. Сопоставлять с конкретным значением после проверки контекста. **CEFR-J / Octanove.** Зафиксировать версию, лицензию конкретного файла и область метки, сверить язык, написание и POS. Метку статьи не наследовать всем значениям автоматически. Другие источники остаются резервными. [Матрица кандидатов](DATABASE_POC_CHAT_REPORT.md)
