Срез относится к локальной рабочей копии Android-фундамента. Паспорт задаёт требования продукта, а HANDOFF от 24 ноября определяет границы стадий. Приёмка первой стадии ещё предстоит.

| Статус | Что установлено |
| --- | --- |
| Implemented — реализовано | Модуль Android, сборка debug APK, семь маршрутов с пустыми состояниями, ввод и очистка запроса, возврат между экранами, сохранение состояния задачи через ViewModel. |
| Partially implemented — частично | У словаря, статьи, личного словаря, подборок, повторения, прогресса и настроек есть представления. Доступность словаря определяется репозиторием, который сейчас возвращает пустой набор языков. |

## Functional Android Application

В Android подключены проверка и загрузка пакета v1, поиск EN ↔ RU по заголовкам, переводам и формам, отображение статьи и атрибуции. В debug используется локально генерируемый искусственный пакет из трёх статей и четырёх значений. Личная база Room хранит слова и значения, переводы, заметки, подборки, карточки и историю. Экспериментальное расписание и статистика читают локальные данные.

Локально прошли 43 из 43 Python-тестов и 9 из 9 JVM-тестов. Debug, release и тестовый APK собраны. Lint завершился с нулём ошибок и тремя предупреждениями о версиях зависимостей. Проверка содержимого APK подтвердила наличие искусственного пакета только в debug. Десять инструментальных сценариев скомпилированы. ADB не обнаружил устройства, список настроенных AVD пуст.

Реального допущенного корпуса нет. Очередь из 24 редакторских задач доступна локально в JSONL и CSV. Права и редакторские решения не изменялись. Контракт пакета v2 и проверка на Android API 29, в том числе воспроизведение локальным голосом, остаются открытыми. [Порядок запуска и ручная приёмка](TEST_PLAN.md)

## Dictionary Release Pipeline и Android Readiness

В экспериментальном Python-прототипе добавлены отдельные решения редактора и проверки прав, реестр постоянных UUID, группировка поиска по смыслу, индекс форм и экспорт проверяемого пакета. Тесты на искусственных данных подтверждают повторяемый экспорт и отказ при отсутствии допустимого содержимого. Реальная выборка содержит 153 задачи и 458 pending-свидетельств. Из неё выделены 24 локальных AI-assisted предложения. Редакторских одобрений и допущенных к выпуску записей нет.

Проверка на Windows дала **42/42 Python-теста** и **7/7 Android JVM-тестов**. Debug APK и тестовый APK собраны, lint завершился с 0 ошибок и одним прежним предупреждением Lifecycle. Два новых сценария SQLite и ICU входят в набор из семи инструментальных тестов. ADB не обнаружил устройства, поэтому выполнение Android-сценариев остаётся открытым. Окончательная схема, реальный пакет и ручная приёмка Foundation ожидают утверждения.

## Основания для работы с данными

**Dictionary Data Foundation, 25 ноября 2026 года.** На Windows после исправления незакрытого SQLite-соединения прошли 23 исходных теста. Расширенный прототип проверяет происхождение, транзакции, выборку, фильтрацию прав и ручную классификацию. Выполнены четыре локальных импорта из доступного снимка Kaikki и синтетический desktop benchmark. Решения по значениям и правам остаются на проверке. [Локальные результаты и предложение контракта](DATABASE_POC_REPORT.md)

**Database Design Draft, 25 ноября 2026 года.** На основании сохранённых результатов аудита предложены логическая и физическая модели словарного и личного хранилищ. Статус — **черновик, не утверждён**. Есть описание идентичности значений, прав на элементы, двустороннего поиска, связей и индексов. Существующий Android-репозиторий данных возвращает пустой набор языков. Реализация, измерения на устройстве и проверка миграций остаются запланированными. [Проект модели](DATABASE_DESIGN_DRAFT.md) · [ER-диаграммы](DATABASE_ERD.md)
