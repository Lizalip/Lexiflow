### Короткий ручной прогон

1. Открыть синтетический словарь на Samsung в портретном и альбомном окне. Сверить панель, боковые отступы, клавиатуру и кнопку очистки. При увеличенном шрифте пройти статью с переносом строк.
2. Найти форму и затем открыть статью в обратном направлении. Сверить исходное написание, раздел форм, переводы по значениям и атрибуцию.
3. Сохранить значение, изменить личный перевод и заметку. Пролистать список, открыть статью, вернуться к прежней позиции. Удалить подборку и снова найти сохранённое слово.
4. Раскрыть карточку, пересоздать экран поворотом, оценить ответ и сверить итог с прогрессом. На API 29 отдельно повторить запуск и поиск в авиарежиме.

## Демонстрация для курсовой

1. Запустить debug на API 29 с малым искусственным V2-пакетом. В авиарежиме найти `zeta-demos`, переключить направление и открыть статью по запросу `демо-объект`.
2. Показать раздельные переводы, пример, метаданные и атрибуцию. Сохранить значение, добавить заметку и членство в подборке.
3. Создать карточку, раскрыть ответ и оценить повторение. После перезапуска показать сохранённую запись и счётчики.
4. Показать агрегированные результаты отбора и разницу между кандидатом, редакторским решением и допуском к экспорту. В курсовой отметить искусственный демонстрационный корпус, desktop-метрики и фактический статус устройства.

Для записи демонстрации нужен настроенный AVD API 29 или подключённое устройство. [Инструкция запуска](TEST_PLAN.md)
