# Проверка глосс и прав для первого словарного пакета

Откройте локальный `research/data/review/milestone_release_priority.csv` или одноимённый JSONL. Очередь содержит 24 предложения, исходные идентификаторы, SHA, локаторы, POS, исходную глоссу, примеры при наличии и пояснения. Статус `ai-assisted` означает предварительное предложение.

1. Откройте исходную статью и нужное значение. Проверьте смысл по части речи и примеру. Отдельно классифицируйте переводный эквивалент, определение, смешанную глоссу, отсылку к форме или неясный случай. В неоднозначном случае оставьте предложение открытым и запишите, какое доказательство нужно.
2. Для одобряемой переводной части запишите только выражение, соответствующее конкретному смыслу. В новый локальный JSONL поместите `entry_id`, `sense_id`, `snapshot_sha256`, `locator`, `classification`, `proposed_translation`, `decision`, `reviewer`, `method` и `reason`. В проверенной человеком строке используйте `approved` и `human` с указанием проверившего. Отсутствующий перевод храните как JSON null.
3. Отдельно проверьте страницу, историю, лицензию, условия повторного распространения, атрибуцию и сделанные изменения. Для каждого включаемого элемента составьте запись о правах. Глосса, производный перевод, пример и его перевод имеют разные локаторы. Для аудио и изображений нужны условия конкретного файла. Формат входного JSONL и поля описаны в [редакторском процессе](DICTIONARY_RELEASE_PIPELINE.md).
4. Работайте с локальной копией staging. Сначала выполните `review_queue.py validate`, затем `apply`. Установите права через `release_package.py rights` только после отдельной проверки. Присвойте постоянные ID через `release_package.py bind` статье и каждому одобренному смыслу.
5. Проверьте счётчики через `release_package.py readiness STAGING --registry REGISTRY`. Проверьте полноту обязательных полей для согласованного пилота. Создайте новый каталог командой `release_package.py export STAGING REGISTRY NEW_PACKAGE CORPUS_VERSION --schema-version 2`. Затем выполните `release_package.py validate NEW_PACKAGE`. Пригодная статья требует одобренного перевода и раздельного допуска для статьи, значения, исходной глоссы и производного перевода. Пустой выпуск отклоняется.
6. После отдельного согласования поставки используйте отдельную локальную debug-сборку и тестовый профиль для установки проверенного пакета. Найдите один утверждённый смысл в обоих направлениях и проверьте атрибуцию, связь с исходной статьёй, перезапуск и сохранение личных данных при замене. Механизм публичной поставки ожидает согласования.

Для дополнительного английского источника `english_edition_candidates` выделяет определения, сырые пометы, IPA и несопоставленные кандидаты переводов из одной записи. Контракт проверен на искусственных объектах. Связь смысла другого словаря выбирается редактором по контексту. Систематическое покрытие дополнительного снимка в этой задаче не измерялось.

## Редакторское рабочее место FreeDict

На существующей очереди из 200 написаний `editor_workspace.py` готовит локальную таблицу и автономный HTML. Интерфейс показывает POS, кандидата, число исходных вариантов, локаторы, ID владельца определения, раздельный статус прав и причину приоритета. Браузер выгружает выбранные строки в JSONL со статусом `proposed`. Редакторские решения для применения передаются отдельно через проверку `review_queue.py validate` и транзакционный `apply`. Связь определения подтверждается отдельно командой `release_package.py context`. Экспорт из браузера не редактирует staging.

Из корня проекта укажите новый каталог под `research/data/review/`.

```powershell
python research/prototypes/sqlite_poc/editor_workspace.py research/data/processed/enrichment_freedict.sqlite research/data/processed/pilot_ranked_5000.sqlite research/data/review/enrichment_freedict_pilot_200.csv research/data/review/release-candidate
```

Подкаталог содержит `freedict-review.html`, `freedict-context.csv` и `multiword-review.csv`. Фиксированный seed даёт 72 многословных кандидата из полного FreeDict и прежней выборки Kaikki на 5 000 написаний. В каждом источнике выбирается до 12 написаний на страту с сохранением исходного смысла и локатора. Среди восьми многословных написаний диагностического набора FreeDict содержит семь и выборка Kaikki — три. Частоты выражений не вычислялись. Пометка многословного глагола направляет на ручную проверку фразового значения. Данные и очередь остаются локальными.
