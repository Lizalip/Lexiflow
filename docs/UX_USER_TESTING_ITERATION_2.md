## Учебная механика

Очередь берётся из личной базы с учётом режима, сроков и подборки. До трети лимита резервируется на дополнительные попытки. При наличии однозначных вариантов приложение задаёт два вопроса по значению, смешивая EN → RU и RU → EN. Варианты берутся из ограниченной лексической выборки общего словаря и сохранённых записей. Исключаются уже известные альтернативы текущей статьи и визуальные дубли. При обратном вопросе исключаются кандидаты с такой же исходной трансляцией по индексируемому заголовку. Если допустимых вариантов мало, возможны два или три ответа или пропуск вопроса. Для произвольного личного перевода обратное задание предлагается, только если эта формулировка подтверждается у значения.

Ошибка добавляет один повтор того же задания, когда остаётся место. При наличии других заданий повтор откладывается, при повторном показе варианты перемешиваются. После ответа отмечаются верный и выбранный неверный вариант. Один вопрос принимает один ответ. Текущая очередь, позиция и ответ сохраняются при пересоздании окна.

Оценка в конце занятия относится к значению. Последняя ошибка даёт 0. Успех после ошибки или проверка только одного направления дают 1. Безошибочная проверка обоих направлений даёт 2. Интервалы остаются прежними. Сохранение событий и сроков выполняется одной транзакцией с проверкой ожидаемого срока. Если в старой базе у значения несколько просроченных карточек, их сроки обновляются вместе, а в историю добавляется одно событие. Будущий срок старой карточки сохраняется. Результат показывает отдельную точность по попыткам.

## DATA-001 и DATA-002

Порядок `one` сохранён. Исходное значение с POS numeral начинает список с «раз», а отдельного приоритета у переводов нет. Пакет не содержит английских заголовков `cafe` и `café`. `cafeteria` попадает в поиск по префиксу `cafe`. В RU → EN есть отдельная статья «кафе».
