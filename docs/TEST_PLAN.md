# Проверки Android-клиента LexiFlow

## Морфология и расширенные примеры

`scripts/verify-research-upgrade.ps1 -Python <python.exe> -Advanced morphology -LexicalScale` последовательно сохраняет синтетические личные данные в изолированном профиле, обновляет словарь, измеряет отдельные фазы активации, проверяет формы и примеры, перезапускает процесс и откатывает пакет. Все шесть сценариев прошли на Samsung SM-X516B API 34. `-ProfileOnly` запускает отдельный фазовый прогон и целевую проверку неверного владельца метаданных.

Штатный Research APK активирован после изолированной проверки. AAPT подтвердил минимальный API 29 и отсутствие разрешения `INTERNET`. Рантайм API 29 требует установленного AVD или отдельного устройства. Физический авиарежим входит в ручную приёмку. [Версии, размеры и задержки](OVERNIGHT_CHECKPOINT.md)

На текущей ревизии прошли 82 Python-теста, 19 JVM-тестов и 34 теста стандартной регрессии Samsung. Три отдельных режима пропущены по условиям запуска, включая фазовый тест Research в этой стандартной конфигурации. Ошибок и новых аварий 0. Отдельно прошли шесть сценариев обогащённого пакета. Отказ на пропущенном владельце заметки или неверном языке CEFR проверен стандартной регрессией. Собраны debug, release, тестовый и Research APK. Проверены исключение исследовательских ассетов из обычного выпуска и ожидаемый отказ production gate. Локальный `lintDebug` обнаруживает `PropertyEscape` в `local.properties`. Lint с `ANDROID_HOME` на копии исходников прошёл.

## Расширение прямого RU–EN

`scripts/verify-research-upgrade.ps1 -Python <python.exe> -Advanced bilingual-expansion -DirectWord 'дом' -AddedWord 'абрис'` проверяет 20 000 английских и 20 000 русских написаний. Временный профиль устанавливает действующий корпус, сохраняет в Room английские и русские смыслы с пользовательскими дополнениями, затем обновляет словарь, открывает и сохраняет добавленный русский смысл, перезапускает процесс и откатывает пакет. Тест ожидает, что старый русский смысл доступен после отката, а новая личная запись остаётся со статусом недоступной статьи.

Пять запусков AndroidJUnitRunner прошли на Samsung SM-X516B API 34. Сравнение пары выполнялось до установки и включало язык, стабильные ID, значения, тексты и канонические поля атрибуции. Данные теста лежат в отдельном профиле. [Итоги и производительность](OVERNIGHT_CHECKPOINT.md)

В режиме `-Advanced content` один сценарий открывает прежний однопарный пилот, второй после обновления проверяет несколько примеров, раздельные кредиты, поиск формы и показ грамматики. Оба сценария прошли. Два снимка получены из кэша тестового приложения. Пересобранный обычный debug дал 33 пройденных теста и два opt-in пропуска на Samsung. Регрессия включает тест отбора английского офлайн-голоса и отказ при отсутствии подходящего голоса.

Прошли 80 Python-тестов и 18 JVM-тестов. Собраны обычные debug, release, тестовый APK и Research. Пройден lint на копии исходников с `ANDROID_HOME`. В рабочей папке lint зафиксировал `PropertyEscape` в локальном пути SDK. Обычный release проверен на отсутствие словарных и синтетических ассетов. Путь production gate отклонил пакет Research даже с корректным SHA манифеста. Минимальный API 29 подтверждён через AAPT, установленного AVD для рантайм-проверки не найдено. Проверенные APK не запрашивают `INTERNET`.

## Двуязычный пакет и формат 3

Запустите `scripts/verify-research-upgrade.ps1 -Advanced bilingual -DirectWord 'дом'` с действующим SDK, JDK и Python в Windows. Временный профиль устанавливает исходный пакет, сохраняет смысл, обновляется до SQLite V3, сохраняет русскую статью с личным переводом, добавляет её в подборку и повторяет карточки в обоих направлениях. Отдельные вызовы раннера проверяют перезапуск и откат. Обычный Research сохраняет свой Android ID и пользовательское хранилище.

`AdvancedManifestTest` проверяет восстановление компактной атрибуции и отказ при неверных индексах, форме таблицы, контрольной сумме и версии. `PackageReceiptTest` проверяет повторную полную валидацию при устаревшей квитанции. `TranslationDisplayTest` проверяет отображение простых ссылок и сохранение неизвестной разметки. Прошли 76 Python- и 18 JVM-тестов, собраны debug, release и тестовый APK. В обычном release исследовательские ассеты отсутствуют. Production gate отклонил исследовательскую пару с корректным SHA. Lint прошёл на копии исходников с SDK через `ANDROID_HOME`. Lint в исходной папке возвращает `PropertyEscape` для локального пути SDK.

Для ручной проверки откройте `book` с двумя POS и сравните уровни CEFR-J. По русскому запросу `дом` проверьте собственную статью перед обратной выдачей и отсутствие английского озвучивания. Для `мир` сравните независимые статьи, для `книга` проверьте обратный результат. На сохранённой русской статье откройте карточки обоих направлений. Офлайн-приёмка в авиарежиме, Android 10 и устройство с 3 ГБ ОЗУ остаются отдельными проверками. [Замеры и ограничения](OVERNIGHT_CHECKPOINT.md)

На Samsung API 34 стандартный изолированный прогон дал 33 пройденных теста из 35. Два сценария загрузки 100 000 искусственных статей и отдельного дизайн-профиля требуют параметров запуска. В отдельных прогонах прошли четыре проверки двуязычного обновления, две проверки двуязычного пакета с CEFR-J и одно открытие полного EN–RU. Новых аварий в журналах этих прогонов нет.

Пилот Tatoeba проверен отдельным AndroidJUnitRunner на Samsung. Тест открыл блок примера употребления, подтвердил раздельные ссылки атрибуции и отсутствие позиций примера внутри конкретных значений. Пять целевых тестов квитанции версии 4 и парсера также прошли на устройстве. Python-проверка набора из 77 тестов включает отказ при изменении текста, языка или POS владельца. Обычный release отклоняет пилот при верном SHA манифеста. AAPT подтверждает API 29 в манифесте и отсутствие разрешения `INTERNET` в проверенных APK. Доступен рантайм Android 14.

## Ночной прогон с 20 000

Версия активного пакета и IPA в видимой области статьи проверены на 20 000. Для русского поиска проверены `понимать`, `устойчивый`, исходное написание с ударением, буквальный сценарий `книга` и выдача по нескольким частям речи.

Для воспроизведения используйте `verify-research-upgrade.ps1`. Параметр `-CheckRollback` включает пару проверок сохранения личных данных при исчезновении статьи. Ключ `-UpdateResearch` обновляет существующую исследовательскую установку только после проверки изолированного профиля. Актуальные размеры и измерения находятся в ночной записи. ## Real Dictionary Integration

Локальная пара FreeDict 5 000 прошла упаковку и проверку в Gradle, сборку debug и тестового APK. На Samsung SM-X516B API 34 прошли оба сценария `RealResearchFlowTest`. Первый проверил два направления поиска, статью и личные данные, второй открыл их после остановки процесса. Новых аварий процесса 0. Две проверки выполнены отдельными вызовами AndroidJUnitRunner. Скрипт использует отдельный отладочный пакет и проверяет отсутствие установленной копии, прежде чем начать. После тестов чистая исследовательская установка оставлена на Samsung.

Python 69/69 и JVM 14/14. Прошли обычные `assembleDebug`, `assembleRelease` и `assembleDebugAndroidTest`. APK отдельно проверены по ZIP и AAPT. Исследовательский APK включает только пару `dictionary-research` с точным совпадением SHA-256 обоих файлов. В обычном release нет SQLite или словарных ассетов. Выполнение `:app:prepareApprovedDictionary` с исследовательской парой и верным SHA-256 манифеста завершилось ожидаемым отказом.

В стандартном изолированном профиле на Samsung прошёл 31 тест, не запущены 2 opt-in сценария с дизайн-профилем и 100 000 искусственных статей. Тестовых ошибок и новых аварий 0. Lint той же версии исходников на локальной копии с `ANDROID_HOME` прошёл. Локальный файл настроек сохранил исходный SHA.

Для ручной проверки открыть LexiFlow Research, найти `book`, открыть статью, сохранить значение, добавить заметку, пройти карточку и повторить поиск `книга` после перезапуска. Для проверки офлайн включить авиарежим отдельно. Android 10, наличие голоса, системное восстановление задачи после гибели процесса и сценарий с 3 ГБ ОЗУ требуют отдельного прогона. ## Подготовка и запуск

В PowerShell из корня репозитория создайте локальный пакет debug. Для первого запуска понадобится Python 3.10+ и SQLite, поддерживающий оконные функции для тестов экспортёра. Путь пакета должен быть новым. Если пакет уже существует, используйте его или сохраните прежнюю копию вне каталога debug assets перед генерацией.

```powershell
New-Item -ItemType Directory -Force research/data/processed/android-debug-assets
python research/prototypes/sqlite_poc/debug_package.py research/data/processed/android-debug-assets/dictionary
python research/prototypes/sqlite_poc/debug_package.py research/data/processed/android-debug-assets/dictionary-v2 --schema-version 2
python -m unittest discover -s research/prototypes/sqlite_poc -v
.\gradlew.bat assembleDebug lintDebug assembleDebugAndroidTest assembleRelease
.\gradlew.bat --gradle-user-home .gradle/verification testDebugUnitTest
```

Затем откройте корень проекта в Android Studio, выполните Gradle Sync, выберите variant `debug` и запустите `app` на API 29+. Для `connectedDebugAndroidTest` используйте отдельную чистую тестовую установку и подготовленный debug-пакет. В release ожидается пустое состояние отсутствующего корпуса. Пакет debug получается из искусственных технических данных с отдельными постоянными UUID.

На Windows для проверки минимального API откройте **Tools → Device Manager → Create Virtual Device**, выберите телефон и образ **Android 10 / API 29, Google APIs x86_64**. Если образ отсутствует, установите его через Device Manager или SDK Manager. Запустите AVD, проверьте, что `adb devices -l` показывает `device`, и выполните `.\gradlew.bat connectedDebugAndroidTest`. Можно использовать подключённый Android 10 с USB-отладкой. Наличие платформы компиляции SDK 37 само по себе не даёт образа Android 10.

## Регрессия BUG-001

`NavigationTest.launchShowsDictionaryStateAndTabsSwitchSections` запускает `MainActivity`, проверяет корневой экран, нижнюю навигацию и отсутствие иконки возврата. `settingsReturnsToProgressThenBackToReview` проходит маршрут «Повторение → Прогресс → Настройки → Прогресс → Повторение». Тест проверяет, что стрелка появляется на вложенных экранах, обрабатывает нажатия и исчезает после возврата в корень.

Для проверки поверх существующей установки подготовьте debug APK и малые искусственные пакеты V1/V2, проверьте единственное целевое устройство через ADB. Устанавливайте приложение через `adb install -r`. Для инструментального запуска на физическом устройстве оставляйте установленные APK и отключайте удаление при несовместимой подписи:

```powershell
.\gradlew.bat --gradle-user-home .gradle/verification `
  -Pandroid.injected.androidTest.leaveApksInstalledAfterRun=true `
  -Pandroid.experimental.testOptions.uninstallIncompatibleApks=false `
  :app:connectedDebugAndroidTest
```

Проверяйте записи `AndroidRuntime` в буфере `crash` по процессу `app.lexiflow` с момента начала проверки. Для BUG-001 подтверждены два холодных запуска на Xiaomi 2502FRA65G с Android 16 (API 36) и 0 новых аварий LexiFlow в окне проверки. `assembleDebug` и `assembleDebugAndroidTest` завершились успешно. `testDebugUnitTest` — 11 из 11, `connectedDebugAndroidTest` — 10 из 10. Ошибок и пропусков в отчётах тестов нет. Минимальный Android 10 (API 29) требует отдельного прогона.

`lintDebug` завершился с 0 ошибок и 3 прежними предупреждениями о версиях Lifecycle и Room. Первичная проверка выдала `PropertyEscape` для экранированного пути SDK в локальном `local.properties`. Повторный анализ использовал `ANDROID_HOME` вместо этой строки. Исходный файл восстановлен побайтно.

## Ручная приёмка

- [ ] Откройте словарь в авиарежиме. Введите `zeta`, затем `zeta-demos`. Проверьте разные значения, поиск по форме и маркировку тестовых данных.
- [ ] Переключитесь на RU → EN и введите `демо-объект`. Откройте статью, проверьте раздельные смыслы, пример с переводом и атрибуцию. Поверните устройство, вернитесь в поиск и проверьте черновик.
- [ ] Дважды сохраните одно значение. В личном словаре проверьте одну запись, добавьте свой перевод и заметку. Создайте и переименуйте подборку, добавьте запись и уберите её из подборки.
- [ ] Создайте карточки обоих направлений. Раскройте ответ, оцените его и проверьте фактические счётчики. Перезапустите приложение и проверьте личные данные и историю.
- [ ] На устройстве API 29 проверьте клавиатуру, поворот, крупный шрифт и TalkBack. Отдельно прогоните тесты ICU и SQLite.
- [ ] В тестовом профиле с V1 сохраните значение, заметку и карточку. В настройках установите встроенный V2. Проверьте статус, сохранность личной базы и появление IPA, определения, глоссы и атрибуции в статье. В соседнем смысле без метаданных поле должно отсутствовать.
- [ ] Быстро смените запрос и направление, затем перейдите в настройки во время загрузки. Вернитесь в поиск и проверьте последнюю выдачу и позицию прокрутки.
- [ ] В изолированном профиле проверьте переходы между страницами личного словаря и подборки, восстановление после поворота и возврат к последней странице до и после удаления записи.

## Инструментальная проверка компактного формата и объёма

`FunctionalDictionaryTest` использует искусственный пакет и отдельный каталог. Он сравнивает результат чтения статьи с плоской и компактной атрибуцией. Повторяющийся ключ, отсутствующие политики, неверный индекс или тип ссылки, изменённая лицензия и повреждённая SQLite должны отклоняться. Проверяются активный указатель и повторное открытие прежнего пакета после отказов.

`RuntimeScaleTest` строит отдельную базу Room с 10 000 сохранениями и 100 подборками. Проверяет границы страниц, индекс, внешние ключи, дубликаты карточек, оба направления и запись оценок. Тест навигации проверяет обратный поиск и открытие смысла на настоящем UI.

`IsolatedPersonalFlowTest` выполнен отдельно на Xiaomi и использует только свежую установку `app.lexiflow.runtimecheck`. Он проходит через UI от поиска до сохранения смысла без дублей, своего перевода и заметки, создания и переименования подборки, добавления записи, двух направлений карточек, раскрытия ответов и обновления статистики. Затем меняет активный пакет с V1 на V2 и повторно открывает Activity, проверяя сохранённую запись. Для сборки двух APK используйте `-Plexiflow.isolatedRuntimeCheck=true` с `assembleDebug assembleDebugAndroidTest`. Файлы создаются в `.gradle/runtimecheck-build/app/outputs/apk`. Проверенный способ установки на Xiaomi — `adb install-multi-package -r -t` с обоими APK. Затем запустите `adb shell am instrument -w -e class app.lexiflow.ui.IsolatedPersonalFlowTest app.lexiflow.runtimecheck.test/androidx.test.runner.AndroidJUnitRunner`. При локальном прогоне после проверки удалены только временная установка и её тестовый APK.

Для сравнения упаковок положите пары `manifest.json` и `dictionary.sqlite` в четыре подкаталога `research/data/processed/android-test-assets/runtime-scale/` с именами `5000-flat`, `5000-compact`, `20000-flat`, `20000-compact`. Их можно создать через `scale_fixture.py --entries N` и `scale_fixture.py --entries N --compact`. Сравните SHA-256 SQLite в каждой паре. Эти ассеты входят в тестовый APK. Тест запускается при наличии всех четырёх пар и не менее 500 МиБ свободного места. Результаты пишутся в Android Logcat с тегом `LexiFlowScale` и сохраняются в отчётах connected tests. Используется отдельный временный каталог для каждой пары. Обычный словарь приложения сохраняется.

Для тёплого запуска пересоздавалась задача LexiFlow при сохранении процесса. Измерения относятся к отображению Activity. Для изолированной Room на 10 000 записей и 100 подборок запрос последней страницы дал 0,62 / 0,84 мс, страницы элементов подборки — 0,59 / 0,73 мс. ## Офлайн-приёмка и Android 10

Релизный APK запрашивает служебное signature-разрешение динамических получателей. `INTERNET` и `ACCESS_NETWORK_STATE` отсутствуют. Поиск, статья, сохранения, подборки, повторение и статистика работают с локальным пакетом и Room. TTS использует Android-службу и выбирает только уже установленный английский голос без требования сети. Тест с подставными голосами проверил отказ от сетевого и неустановленного голоса и переход ко второму локальному, если первый отвергнут. На Samsung служба ответила и подходящего английского голоса не предоставила. Аудио в этой проверке не воспроизводилось.

Для ручной приёмки в изолированном профиле установите пакет, включите авиарежим вручную, запустите LexiFlow с закрытым процессом и проверьте поиск в обоих направлениях, статью, сохранение, подборку, карточку и статистику. Если произношение доступно, проверьте однократное чтение слова. Если локального голоса нет, проверьте доступность карточки статьи, IPA и остальных действий. В конце восстановите сетевые настройки тестового устройства. Физический авиарежим в текущем прогоне не включался.

В установленном SDK есть образы Android 30 и 37.1. Образа API 29 нет, список AVD пуст. Для рантайма API 29 откройте Android Studio → Device Manager → Create Virtual Device, выберите профиль телефона и образ Android 10 / API 29 подходящей архитектуры, затем запустите AVD. При подтверждённой установке образа проверьте через `adb -s SERIAL shell getprop ro.build.version.sdk` результат `29`.
