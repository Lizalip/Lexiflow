# Экспериментальный словарь Android

Словарный SQLite версии 1 открывает `LocalDictionaryRepository` в read-only. В debug он устанавливает пакет из assets в приватный каталог. `install` проверяет новый пакет до переключения указателя `AtomicFile`. При отклонении кандидата используется прежний каталог и прежнее соединение. Клиент различает загрузку, отсутствие, несовместимость, повреждение и ошибку чтения. Экран импорта внешнего файла пока отсутствует.

Проверки включают версии формата и схемы, SHA-256 файла, число строк, целостность SQLite, внешние ключи, индексируемые колонки и ссылки на атрибуцию. Android пересчитывает поисковые ключи средствами ICU и отклоняет несовпадающий пакет. Эта проверка может занять больше времени на реальном корпусе. SHA-256 обеспечивает проверку совпадения файлов, а подлинность потребует доверенного канала поставки или подписи. Следующий этап должен проверить полные общие Unicode-векторы на API 29 и на актуальном Android.

Поиск выполняет диапазонные запросы по индексам статей, форм и переводов, группирует по идентификатору значения через `GROUP BY` и берёт не более 50 результатов. Запросы используют параметры. Порядок отдаёт приоритет точному совпадению. Оконные функции в Android-поиске отсутствуют. `FoundationViewModel` отложенно запускает поиск на одном рабочем потоке и сверяет поколение запроса перед доставкой. Маршрут, запрос, направление и выбранные идентификаторы сохраняются через `SavedStateHandle`.

## Совместимость контракта

Текущая версия уже содержит статьи, POS, значения, переводы, формы, примеры, переводы примеров и происхождение. IPA и варианты произношения, дефиниции, редакционные глоссы, грамматические признаки, стилистика, регион и CEFR потребуют расширения. Предлагается отдельная версия 2 с таблицами дополнений по постоянным ID. Клиент должен сохранить путь чтения версии 1 и явно выбрать схему версии 2 после согласования. База v1 не мигрирует на устройстве. Пропущенные поля не отображаются. Для экспериментальной озвучки кнопка появляется при доступном английском голосе, который движок помечает как установленный и локальный. Реальное воспроизведение без сети предстоит проверить на устройстве.

SQLite read-only позволяет проверять поставляемую схему отдельно от приложения. Room применяется для локальных пользовательских данных. Использование Room для словарного снимка потребует совпадения схемы и Room identity hash при поставке. Окончательный формат словаря остаётся открытым.
